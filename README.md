# Техника высоких напряжений — материалы для студентов

Сайт: https://serev-lab.github.io/tvn/

| Папка | Что внутри |
|---|---|
| `index.html` | Главная страница со списком лекций |
| `i/` | Интерактивы (одиночные HTML-файлы) |
| `m/` | Студенческие материалы: страница для чтения (`.html`) и PDF |
| `qr/` | QR-коды: `qr/index.html` — лист для печати, PNG — для слайдов |

## Как добавить материал самому

1. Откройте нужную папку в репозитории → **Add file → Upload files**.
2. Перетащите файл. Имя — латиницей, без пробелов, например `i/corona.html`.
3. Нажмите **Commit changes**. Через 1–2 минуты файл доступен по адресу
   `https://serev-lab.github.io/tvn/i/corona.html`.
4. Чтобы файл появился на главной, отредактируйте `index.html` (значок карандаша) — или попросите Claude обновить главную.

Замена файла с тем же именем обновляет материал, а адрес и QR-код остаются прежними.

**Не загружайте сюда** ключи, ответы, пособия и инструкции преподавателя: репозиторий публичный.
