1. Вакуумный выключатель и фронт на кабеле

Полюс выключателя содержит герметичную камеру, неподвижный и подвижный контакты. Сильфон позволяет подвижному выводу перемещаться при сохранении вакуума. При отключении контакты расходятся. После их размыкания кратковременный пробой промежутка сопровождается ВЧ-током, а контакты остаются разомкнутыми.

Рис. 1. Вкладка «Повторные пробои». Кадр вращаемого разреза. На контактах видна дуга, на моторном кабеле — положение фронта при B = 14,85 мкс.

Откройте «Показать 3D-разрез». Поворачивайте модель мышью, касанием или стрелками. Кнопка «Закрыть разрез» показывает оболочку, а «Исходный ракурс» восстанавливает вид. Кнопка «Проследить фронт» замедляет короткий участок записи вокруг события.

x=v⋅(t−tсоб)tпробега=ℓvx\ = \ v \cdot (t\ - \ t_{соб})\ \ \ \ \ t_{пробега}\ = \ \frac{\ell}{v}

На отдельной линии визуализации ℓ = 120 м и v = 180 м/мкс. Получается 0,667 мкс. При старте фронта в 14,60 мкс и отсчёте 14,85 мкс прошло 0,25 мкс. Маркер занимает положение 45 м. 2. Срез тока и баланс энергии

Перед естественным нулём малый индуктивный ток может быть прерван выключателем. В контуре двигателя и кабеля остаётся энергия. При принятом знаке положительный ток L заряжает C. После разрыва ток через контакты равен нулю, ток L продолжает течь в отключённом контуре.

Для идеального параллельного LC после разрыва iL = C·du/dt и L·diL/dt = −u. Начальные условия u(0) = U₀ и iL(0) = Iₛ. В момент экстремума C ток индуктивности равен нулю, поэтому весь запас энергии сосредоточен в C.

½LIₛ²+½CU₀²=½CUₘ²½LIₛ²\ + \ ½CU₀²\ = \ ½CUₘ²

Uₘ=U₀²+Iₛ²L/CT₀=2πLCω₀=1LCUₘ\ = \ \sqrt{U₀²\ + \ Iₛ²L/C}\ \ \ \ \ \ \ \ T₀\ = \ 2\pi\sqrt{LC}\ \ \ \ \ \ \ \ \omega ₀\ = \ \frac{1}{\sqrt{LC}}

u(t)=U₀cos(ω₀t)+IₛL/Csin(ω₀t)u(t)\ = \ U₀\ cos(\omega ₀t)\ + \ Iₛ\sqrt{L/C}\ sin(\omega ₀t)

Возьмём L = 40 мГн, C = 0,25 мкФ, Iₛ = 5 А и U₀ = 4 кВ. Характеристическое сопротивление эквивалента √(L/C) = 400 Ом. Вклад Iₛ√(L/C) = 2 кВ. Суммарный идеальный пик 4,472 кВ, опорный период 0,628 мс. Энергия L равна 0,500 Дж, энергия C равна 2,000 Дж. При U₀ = 0 получается частный случай Uₘ = Iₛ√(L/C).

Параллельные потери вводятся как u/R. Тогда C·du/dt = iL − u/R, а dW/dt = −u²/R. С уменьшением R при одинаковом u мгновенные потери растут. В исходном опыте при R = 20 кОм численный пик около 4,434 кВ. Чтобы проверить идеальную формулу, переключите «Учитывать потери» в режим идеальной LC-цепи.

Стартовые опыты

  • Опыт 5. Сохраните запись без потерь. Включите R и измерьте запас энергии после двух опорных периодов.

3. Напряжение на контактах и повторные пробои

Uпром=|Uшин−Uдв|Uпроч(t)=D₀+ktU_{пром}\ = \ |Uшин\ - \ Uдв|\ \ \ \ \ \ U_{проч}(t)\ = \ D₀\ + \ kt

При пересечении |Uшин − Uдв| и Uпроч промежуток становится проводящим в модели. Возникает локальный высокочастотный ток. Модель гасит ВЧ-ветвь около очередного нуля. Ток двигателя в этот момент обычно ещё ненулевой.

Рис. 2. Курсор A отмечает первый пробой 14,60 мкс, B — ВЧ-нуль 22,44 мкс. Интервал первого проводящего состояния 7,84 мкс.

TВЧ≈2πLВЧ⋅CT_{ВЧ}\ \approx \ 2\pi\sqrt{LВЧ \cdot C}

При LВЧ = 32 мкГн и C = 0,16 мкФ опорный период 14,22 мкс. Проводящий интервал определяется и начальным состоянием, нагрузкой, сопротивлением. Источник в расчётном окне 500 мкс задан мгновенным постоянным напряжением. Линейная прочность, RВЧ = 4 Ом и пауза модели — параметры воспроизводимого опыта.

В исходном режиме стенд даёт 10 пробоев за окно. При темпе восстановления 100 кВ/мс пересечений за это время нет. Сравните именно каналы прочности и напряжения на промежутке. Пик напряжения на двигателе может происходить в другой момент.

4. Дуговое замыкание на землю

В симметричной модели фазные ЭДС относительно нейтрали образуют систему со сдвигом 120°. Изменение потенциала нейтрали добавляется ко всем фазам. Поэтому напряжение между фазами сохраняется при идеальном источнике, а их напряжения относительно земли меняются.

Uk–зем=eₖ+UₙUф=Uл3U_{k–зем}\ = \ eₖ\ + \ Uₙ\ \ \ \ \ \ U_{ф}\ = \ \frac{Uл}{\sqrt{3}}

Рис. 3. Проводящее замыкание фазы A в изолированной сети. Напряжения здоровых фаз и смещение нейтрали читаются по отдельным каналам.

IC≈3ωCфUфτразр=3CфRₙI_{C}\ \approx \ 3\omega CфUф\ \ \ \ \ \ \tau_{разр}\ = \ 3CфRₙ

В пределе малого сопротивления замыкания на здоровой фазе действующее напряжение относительно земли стремится к Uл. При Uл = 10 кВ это соответствует фазному пику 14,14 кВ в режиме замыкания. До замыкания фазная амплитуда 8,165 кВ. При 50 Гц и Cф = 0,65 мкФ расчёт установившейся ёмкостной составляющей даёт 3,54 А.

В режиме перемежающейся дуги погасание задано во времени, повторное зажигание зависит от порога. При паузе дуги и изолированной нейтрали заряд сохраняется. Резистор нейтрали даёт путь разряда. Для Cф = 0,65 мкФ и Rₙ = 260 Ом оценка постоянной времени 0,507 мс. Параметры сети и критерии компенсации выбирают по применимым условиям ПУЭ 7, п. 1.2.16.

5. Феррорезонанс

Последовательная ёмкость и нелинейная ветвь намагничивания образуют систему, в которой частота и форма отклика зависят от состояния сердечника. При насыщении производная diₘ/dψ возрастает. При одинаковом напряжении источника результат зависит от начального потокосцепления и заряда C.

im(ψ)=aψ+bψ³diₘdψ=a+3bψ²i_{m}(\psi)\ = \ a\psi\ + \ b\psi ³\ \ \ \ \ \ \frac{diₘ}{d\psi}\ = \ a\ + \ 3b\psi ²

uL=e−uCdψdτ=uLC⋅duCdτ=iₘ+guLuL\ = \ e\ - \ uC\ \ \ \ \ \ \frac{d\psi}{d\tau}\ = \ uL\ \ \ \ \ \ C \cdot \frac{duC}{d\tau}\ = \ iₘ\ + \ guL

Рис. 4. Напряжение ТН, напряжение ёмкости и каналы намагничивания на одной шкале времени.

Время τ = 2πft. В стенде a = 0,40, b управляет нелинейностью, g — потери. При b = 0 ветвь линейна. В опыте 17 при e = 0,35 о.е., C = 1,5 о.е., b = 0,25, g = 0,08 поздний пик около 0,525 и 2,430 о.е. для ψ₀ = 0 и 1,45 соответственно.

Поздний пик оценивают по последним трём периодам расчётного окна из 14 периодов. Устойчивость и классификацию режима для реальной цепи проверяют при более длинной записи, по параметрам ТН и схемы.

6. RC-цепь и измерение защиты

Последовательная цепочка Rₛ–Cₛ подключается параллельно входной ёмкости двигателя. Конденсатор меняет токи и распределение энергии, резистор её рассеивает. В начале опыта обе ёмкости заряжены до U₀, поэтому ток защитной ветви точно в момент среза равен нулю.

iRC=Uдв−UCsRₛdWdt=−Rₛ⋅iRC²i_{RC}\ = \ \frac{Uдв\ - \ UCs}{Rₛ}\ \ \ \ \ \ \frac{dW}{dt}\ = \ - Rₛ \cdot iRC²

Рис. 5. Сравнение режима с RC и базовой кривой без RC. Белый пунктир — встроенный эталон для текущих параметров.

При исходных параметрах стенда 180 Ом и 0,45 мкФ расчёт даёт 4,306 кВ с RC и 4,472 кВ без ветви. Сравнивайте пик и среднюю крутизну на одном интервале, например A = 0, B = 0,04 мс. Средняя крутизна ΔU/Δt в кВ/мс пересчитывается в кВ/мкс делением на 1000.

В реальном приводе оценка требует формы фронта, паспортных характеристик выключателя, кабеля, двигателя и устройства защиты. ГОСТ Р 52565 задаёт общие требования к выключателям. IEC 62271-110 относится к коммутации индуктивной нагрузки, IEC 60071-2 — к координации изоляции. Эти документы имеют разные области применения.

7. Как проводить замер

  • В «Практике» выберите вкладку механизма и нажмите «Открыть исходный режим». Запишите параметры и единицы. Меняйте один параметр за опыт.

  • Установите курсор B щелчком по осциллограмме, ползунком или точным вводом с Enter. Для второго отсчёта сначала запомните A кнопкой «Зафиксировать A».

  • Для сравнения нажмите «Сохранить запись» перед изменением режима. Розовый пунктир — сохранённая запись напряжения. Белый пунктир на RC-стенде — эталон без RC при текущих L, C, U₀ и Iₛ.

  • Развёртка меняет окно просмотра. В режимах замыкания и феррорезонанса частота меняется отдельно. Скорость показа влияет на анимацию.

  • Скачайте CSV, если нужны все отсчёты, события, отметки A и B и параметры. В выводе укажите, что подтверждает измерение и какое принято допущение.
